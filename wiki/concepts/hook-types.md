# 🪝 훅 유형

소재 첫 1~3초나 첫 줄 카피에서 시선을 잡는 방식을 분류합니다. 관찰 사례가 쌓이면 유형을 고치거나 새로 추가합니다.

| 유형 | 설명 | 관찰 사례 |
|---|---|---|
| 문제 제기 | "모공 때문에 고민이세요?" 처럼 고민을 짚음 | |
| 비포/애프터 | 사용 전후 비교 | |
| 숫자/증거 | "누적 100만 개 판매", 임상 수치 | |
| 권위/인증 | 피부과 테스트, 어워드, 전문가 | |
| UGC/후기 | 실사용자 리뷰, 언박싱 | |
| 반전/호기심 | "이거 바르지 마세요" 처럼 궁금하게 만듦 | |
| 성분 강조 | 특정 성분과 함량을 앞세움 | |

## 💡 해석
_사례가 쌓이면 어떤 훅이 오래 집행되는지 정리합니다._
